# Python Projects

A collection of self-taught Python projects, built while preparing for a Level 6 Software Engineering Degree Apprenticeship. Each project focuses on a different core concept — file handling, conditional logic, data persistence, and clean function structure.

## Projects

- **calculator.py** — Command-line calculator handling core arithmetic operations, with input validation to prevent crashes on invalid entries.
- **number_guessing_game.py** — Interactive number guessing game using conditional logic and loops to manage repeated user input and win/lose states.
- **todo_list.py** — Command-line to-do list app with JSON persistence, allowing tasks to be saved and reloaded between sessions.
- **budget_tracker.py** — Budget tracker recording income and expenses with transaction history, persisting data to JSON and calculating running balances.

## How to run

Each script can be run directly with Python 3:

​```
python calculator.py
​```
