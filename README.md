# Python Projects

A collection of self-taught Python projects, built independently using YouTube tutorials and self-directed learning while preparing for a Level 6 Software Engineering Degree Apprenticeship. Each project focuses on a different core concept — file handling, conditional logic, data persistence, clean function structure, APIs and security.

## How I learned
All projects were built independently using YouTube as my primary learning resource, alongside documentation and self-directed practice. No formal Python course — just problem solving, debugging and building.

## Projects

- **calculator.py** — Command-line calculator handling core arithmetic operations, with input validation to prevent crashes on invalid entries.

- **number_guessing_game.py** — Interactive number guessing game using conditional logic and loops to manage repeated user input and win/lose states.

- **todo_list.py** — Command-line to-do list app with JSON persistence, allowing tasks to be saved and reloaded between sessions.

- **budget_tracker.py** — Budget tracker recording income and expenses with transaction history, persisting data to JSON and calculating running balances.

- **password_generator.py** — Secure password generator using Python's random and string modules with list comprehensions, allowing custom length passwords.

- **quiz_game.py** — Interactive tech quiz game with randomised question order, multiple choice logic and score tracking with performance feedback.

- **weather_app.py** — Live weather app using the OpenWeatherMap API to fetch and display real-time weather data including temperature, humidity and conditions for any city.

## How to run
Each script can be run directly with Python 3:
```python weather_app.py```
